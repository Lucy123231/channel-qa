# 知识库维护说明

## 文件结构

```
kb/
├── README.md   ← 本说明
├── kb.json     ← 知识库数据（日常改这个）
└── images/     ← 147张截图
```

## 改文字

用记事本或 VS Code 打开 `kb.json`，找到对应分类，直接改 `title`、`tx`、`w` 字段。

改完运行 `cd ../src && python build.py` 生成新网页。

## 加截图

1. 把新图片放到 `images/` 文件夹
2. 在 `kb.json` 对应步骤里加 `"img": "你的文件名.png"`（单张）或 `"imgs": ["图1.png", "图2.png"]`（多张）
3. 运行 `cd ../src && python build.py`

## 加关键词（提高搜索匹配）

每个分类都有 `kw` 数组，加同义词、口语词、常见错别字：

```json
"kw": ["开户", "新开", "新增经销商", "开新户头", "怎么开户", "如何开户"]
```

改 `kw` 后直接运行构建就行，不用改代码。

## kb.json 字段速查

| 字段 | 说明 | 示例 |
|------|------|------|
| `t` | 板块标题 | `"一、一批商管理——（一）开户"` |
| `intro` | 顶部简介（支持链接） | `"入口：<a href='...'>链接</a>"` |
| `kw` | 分类关键词 | `["开户","新开","新增经销商"]` |
| `s[].title` | 步骤标题 | `"1、户头类型介绍"` |
| `s[].tx` | 正文（`\n`换行） | `"术语和缩略语\n根户头：..."` |
| `s[].img` | 单张图片文件名 | `"1.0.png"` |
| `s[].imgs` | 多张图片 | `["1.2.png","1.3.png"]` |
| `s[].w` | 警告提示 | `"若基本信息未同步..."` |

## 构建命令

```bash
cd ../src
python build.py
```

输出：根目录的 `index.html`

## 特殊板块：一码通办 / 奖励会谈

「一码通办」和「其他事项（奖励会谈）」板块的条目定义在 `src/template.html` 的 `IDX` 中（不在 kb.json 里），
分别引用其他分类的既有内容或等待补充内容：
- 一码通办：引用库存-数据导出路径、交接-转码台账等。问「一码通办/智慧雪花2.0/数据看板/数据报表」强制展示该板块。
- 其他事项（一批签收奖励/二批签收奖励/经销商会谈）：kb.json 中暂无对应章节内容，选中条目会提示联系销管。

这两个板块命中关键词时**不会**落到“不在范围内”话术。
如《渠道管理指南》更新了相关章节，请把内容加到 kb.json 并同步调整 `IDX` 中的 `c`/`s` 引用。

## 知识库结构与版本管理（6域21场景）

kb.json 顶部 `_meta` 记录知识库版本（`ver`），政策变更时更新版本号并在此记录改动。

每个分类带 `dom` 字段标记域归属（与《企业级知识库架构》文档对应）：

| 域 | 分类（kb.json 键） | 场景 |
|---|---|---|
| 一批商管理 | 开户/销户/变更/交接/实控人 | 户头与开户/销户/信息变更/经销商交接/常见问题 |
| 二批商管理 | 二批/特约 | 二批开户销户变更/挂靠关系/特约经销商 |
| 合同与电子签 | 合同 | 合同订立/签署与进度/常见问题/电子签推送函 |
| 库存管理 | 库存 | 盘点/调平/周转/调整 |
| 仓库地址 | 仓库/飞检 | 地址新增/地址变更/地址专项 |
| 激励与数据驱动（空壳） | —（在 template.html IDX） | 一码通办/签收奖励/经销商会谈 |

风险点（必须高亮）维护在 `src/template.html` 的 `RED` 数组：
骑缝章、预包装不可后补、签字按手印、张雅寒、海南甲方、三批P后缀、临期过期酒、渠道调整报告、隐藏库、拼车信息一致、特约转取消标签、推送函法务审核。

新增业务：在对应域的分类下加 section + 关键词（kw）；新增风险点加 RED；政策变更更新 `_meta.ver`。

## 依赖

Python 3 + Pillow + pypinyin：`pip install Pillow pypinyin`

- Pillow：压缩截图
- pypinyin：生成拼音表（模糊匹配用）；未安装时构建照常，仅拼音容错降级为编辑距离容错

## 模糊匹配引擎（错别字/同音字容错）

模板内置中文模糊匹配层（编辑距离 + 拼音），**只在前置精确检索层全部未命中时启用**：

- 拼音前缀命中（同音字，如"一码通版"→"一码通办"）：置信度 HIGH，直接回答
- 编辑距离/拼音相似度 ≥0.55：MEDIUM，列出"您是不是想问"候选让用户确认
- 低于 0.55：继续走原有弱信号引导/无匹配话术

拼音表由 build.py 自动从知识库+模板字符集生成，无需手工维护。
