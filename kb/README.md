# 知识库维护说明

## 文件结构

```
kb/
├── README.md   ← 本说明
├── kb.json     ← 知识库数据（日常改这个）
└── images/     ← 147张截图
```

## 改文字

用记事本或 VS Code 打开 `kb.json`，找到对应分类，直接改 `title`、`tx`、`w` 字段。

改完运行 `cd ../src && python build.py` 生成新网页。

## 加截图

1. 把新图片放到 `images/` 文件夹
2. 在 `kb.json` 对应步骤里加 `"img": "你的文件名.png"`（单张）或 `"imgs": ["图1.png", "图2.png"]`（多张）
3. 运行 `cd ../src && python build.py`

## 加关键词（提高搜索匹配）

每个分类都有 `kw` 数组，加同义词、口语词、常见错别字：

```json
"kw": ["开户", "新开", "新增经销商", "开新户头", "怎么开户", "如何开户"]
```

改 `kw` 后直接运行构建就行，不用改代码。

## kb.json 字段速查

| 字段 | 说明 | 示例 |
|------|------|------|
| `t` | 板块标题 | `"一、一批商管理——（一）开户"` |
| `intro` | 顶部简介（支持链接） | `"入口：<a href='...'>链接</a>"` |
| `kw` | 分类关键词 | `["开户","新开","新增经销商"]` |
| `s[].title` | 步骤标题 | `"1、户头类型介绍"` |
| `s[].tx` | 正文（`\n`换行） | `"术语和缩略语\n根户头：..."` |
| `s[].img` | 单张图片文件名 | `"1.0.png"` |
| `s[].imgs` | 多张图片 | `["1.2.png","1.3.png"]` |
| `s[].w` | 警告提示 | `"若基本信息未同步..."` |

## 构建命令

```bash
cd ../src
python build.py
```

输出：根目录的 `index.html`

## 特殊板块：一码通办

「一码通办」板块的条目定义在 `src/template.html` 的 `IDX['一码通办']` 中（不在 kb.json 里），
它引用其他分类的既有内容（库存-数据导出路径、交接-转码台账等）。
问「一码通办/智慧雪花2.0/数据看板/数据报表」会强制展示该板块，不会落到“不在范围内”话术。
如《渠道管理指南》更新了该章节，请把新内容加到 kb.json 并同步调整 `IDX['一码通办']` 的引用。
